# Fixed Website Package for GitHub Pages

I have cleaned up all image file paths to make them clean, organized, and super easy to manage.

## Folder Structure:
```
islamia-college/
├── index.html
└── images/
    ├── logo.jpg
    ├── hero.jpg
    ├── director.jpg
    ├── sir-mohsin.jpg
    ├── sir-asad.jpg
    └── syed-faraz.jpg
```

---

## How to setup:

1. Extract this ZIP file.
2. Inside the extracted folder, open the `images/` directory.
3. Rename your original image files to match these exact clean names and drop them in the `images` folder:
   - Logo image -> `logo.jpg`
   - Hero background image -> `hero.jpg`
   - Director image -> `director.jpg`
   - Sir Mohsin image -> `sir-mohsin.jpg`
   - Sir Asad image -> `sir-asad.jpg`
   - Syed Faraz image -> `syed-faraz.jpg`
4. Upload both `index.html` AND the `images` folder directly into your GitHub repository!
